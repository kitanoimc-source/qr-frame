# Frames

Ten licensed Crayon Shin-chan photo frames, each a PAIR of transparent PNGs, 1500px wide: `kureyonshinchanNNue.png` (上, top art) and `kureyonshinchanNNshita.png` (下, bottom art).

- Place the top half at `top: 0`, the bottom half at `bottom: 0`, both at the stage width with height from their aspect (capped at the stage height, CONFIG.frameMaxRatio 1.0), centred. The camera shows through the middle.
- Always use both halves of the same number; never mix pairs.
- Character artwork: use exactly as supplied — never crop, recolour, redraw or place UI on top of the characters.
- Thumbnails (`FrameThumb`) show the pair in a 9:16 well.

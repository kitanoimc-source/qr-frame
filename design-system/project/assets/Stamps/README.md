# Stamps

PLACEHOLDERS. The source marks these seven SVGs as temporary (仮スタンプ) until the real stamp art arrives; replace the whole group then.

- Character tab (キャラクター): `placeholder-star`, `-heart`, `-sun`, `-crown`, `-flower` — flat fills with a darker stroke of the same hue.
- Speech-bubble tab (ふきだし): `placeholder-bubbleA` (たのしい), `-bubbleB` (すき！) — white with `#2f2a24` outline and bold text.
- All are 512 × 512, placed at `size-stamp-base` wide. Real stamps should follow the same square canvas with transparent surroundings.
